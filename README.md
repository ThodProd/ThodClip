# ThodClip

Постоянная история буфера обмена и архив скриншотов для **ThodHUB** на Windows x64.

ThodClip запоминает всё, что вы копируете: текст, файлы и изображения. Записи хранятся в SQLite внутри папки данных ThodHUB, поэтому переживают перезапуск, обновление модуля и очистку системной истории Windows. Любую запись можно скопировать обратно одной кнопкой, закрепить или удалить.

В раздел «Скриншоты» попадают изображения из буфера обмена, включая снимки из ThodShot, а также скриншоты из стандартных папок Windows. Архивная копия остаётся доступной после удаления оригинала.

По умолчанию запись работает, пока открыт ThodHUB. В настройках можно включить **«Работать в фоне»**: отдельный процесс продолжит запись после закрытия хаба и запустится вместе с Windows. Фоновый процесс работает из кэша ThodHUB, поэтому обновление и удаление программы не блокируются.

## Возможности

- История текста, файлов и изображений без ограничения по времени (настраиваемый лимит записей).
- Скопировать обратно текст, файлы или изображение; для файлов можно скопировать как сами файлы, так и список путей.
- Поиск по всей истории и фильтры: текст, файлы, картинки, закреплённые.
- Календарь копирования: количество записей за каждый день, переход к нужному дню и группировка истории по дням.
- Длинные тексты свёрнуты в карточке; кнопка «Раскрыть» загружает полный текст.
- Закрепление важных записей — они не удаляются при очистке и ограничении истории.
- Архив скриншотов с превью, полноэкранным просмотром, копированием, сохранением и удалением.
- Скопированная картинка сохраняется как изображение с миниатюрой, даже если программа передала её временным файлом с именем вроде `{GUID}.png` или только ссылкой в HTML.
- Новые записи появляются в списке автоматически; если вы прокрутили историю вниз, показывается кнопка обновления, чтобы не сбить позицию.
- У записей с картинками-файлами показывается маленькая миниатюра, даже если это список из нескольких файлов.
- Один и тот же скриншот, пришедший из буфера и из папки, не дублируется в архиве.
- Импорт уже существующих скриншотов из стандартных папок.
- Фоновая запись после закрытия ThodHUB и автозапуск вместе с Windows (по желанию).
- Настройки повторов, лимитов хранения и исключений Windows.
- Светлая и тёмная темы ThodHUB, адаптация к узкому окну.

## Честные ограничения

- **ThodClip не заменяет Win+V.** Стороннее приложение не может встроиться в системное меню истории Windows. ThodClip ведёт собственную историю и копирует записи обратно через свой интерфейс.
- **Запись без ThodHUB включается отдельно.** Пока фоновый режим выключен, embedded-worker живёт только до закрытия хаба. Фоновый режим — обычный процесс в сеансе пользователя, без службы, драйвера и трея; он запускается из `%LOCALAPPDATA%\ThodHUB\Cache\thodclip` и останавливается при отключении настройки, обновлении или удалении программы.
- Форматирование (RTF/HTML) не сохраняется: текст записывается как обычный Unicode-текст.
- Очень длинный текст обрезается настраиваемым лимитом (по умолчанию 1 МБ, максимум 2 МБ).
- Защищённые данные с флагами `ExcludeClipboardContentFromMonitorProcessing`, `CanIncludeInClipboardHistory=0` или `CanUploadToCloudClipboard=0` не записываются, пока включена настройка исключений.
- Нет облачной синхронизации и шифрования базы: данные лежат локально в папке ThodHUB.

## Установка

1. Откройте ThodHUB → Каталог.
2. Найдите **ThodClip** и нажмите «Установить».
3. Откройте ThodClip. Запись начнётся сразу; состояние видно в правом верхнем углу.

Обновления ставятся через ThodHUB. Предыдущая версия сохраняется хабом для отката, данные при этом не мигрируют и не удаляются.

## Данные и приватность

Все данные находятся только в каталоге данных ThodHUB (`THODHUB_DATA_DIR`), вне папки версии:

```
clip.db                 база SQLite
config.json             настройки
blobs/                  оригиналы изображений из буфера
thumbs/                 превью изображений
shots/orig/             архивные копии скриншотов
shots/thumb/            превью скриншотов
```

- Ничего не отправляется в сеть.
- В репозиторий не попадают пользовательские базы, настройки, токены или скриншоты.
- Фоновый режим добавляет только автозапуск текущего пользователя `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\ThodClip` и копию программы в `%LOCALAPPDATA%\ThodHUB\Cache\thodclip`. Настройка отключается в интерфейсе; при удалении программы запись автозапуска и кэш удаляются.
- Для резервной копии закройте ThodHUB и скопируйте всю папку данных: в режиме WAL отдельный `clip.db` без `-wal` может быть неполным.
- При удалении модуля через ThodHUB данные сохраняются, если не отмечен пункт удаления данных.

### Очистка

- «Очистить историю буфера» в настройках удаляет записи ThodClip; закреплённые можно сохранить.
- «Очистить архив скриншотов» в настройках удаляет только архивные копии, оригиналы в пользовательских папках не трогает.
- Отключение «Работать в фоне» сразу останавливает фоновый процесс и удаляет запись автозапуска.
- Системный буфер обмена и история Windows (Win+V) не изменяются.

## Права модуля

| Право | Зачем |
|---|---|
| `worker` | Запуск `ThodClip.Worker.exe`, доступ к буферу, файлам и SQLite. |
| `files.export` | «Сохранить как…» для скриншотов и изображений (лимит ThodHUB — 8 МБ). |

Модуль не запрашивает `clipboard.write`: копирование выполняет worker через нативный буфер Windows, поэтому работают изображения и списки файлов, а не только текст.

## Сборка

Требования: Windows x64, Rust stable через rustup, компоновщик MSVC или MinGW x64 и PowerShell.

```powershell
rustup target add wasm32-unknown-unknown
$version = (Select-String -Path Cargo.lock -Pattern '^name = "wasm-bindgen"$' -Context 0,1).Context.PostContext -replace '^version = "(.+)"$','$1'
cargo install wasm-bindgen-cli --version $version --locked
cargo test --locked -p thodclip-worker --release
.\scripts\build.ps1
```

Скрипт собирает нативный worker для Windows x64 и интерфейс Rust для WebAssembly. В готовый модуль входят HTML, CSS и мост ThodHUB. Устанавливать Rust или .NET для запуска модуля не требуется.

Результат сборки: `artifacts/thodclip-<version>-win-x64.zip` и `artifacts/thodhub-release.json`. Для сборки без ZIP используйте `.\scripts\build.ps1 -SkipPackage`.

### CI и релиз

GitHub Actions запускается на теге `hub-vX.Y.Z`. Workflow прогоняет тесты на Windows, собирает модуль, сверяет версию, размер и SHA-256 и публикует стабильный релиз с ZIP и `thodhub-release.json`.

### Ручная проверка worker

```powershell
$env:THODHUB_DATA_DIR = "$env:TEMP\thodclip-test"
$env:THODCLIP_SCREENSHOT_ONLY = "1"
$env:THODCLIP_SCREENSHOT_DIRS = "$env:TEMP\thodclip-test\shots"
'{"jsonrpc":"2.0","id":"1","method":"status"}' | .\artifacts\stage-1.1.2\worker\ThodClip.Worker.exe
```
